## 运行测试

### Doctest

使用 Python 标准库的 ``doctest`` 模块，例如：

    $ python3 -m doctest bisect_demo.py -v

### Jupyter Notebook

安装 ``pytest`` 和 ``nbval`` 插件：

    $ pip install pytest nbval

运行：

    $ pytest --nbval
